# story-sandbox

A personal learning project for practicing product-owner and scrum-master
workflows on GitHub stories. The RStudio version uses R's `httr` package to
call GitHub's API directly; it does not require or run the GitHub CLI.

## Start here

1. Open this folder as an RStudio Project (or set it as RStudio's working
   directory).
2. Follow [RSTUDIO.md](RSTUDIO.md) to install the two R packages, save a
   fine-grained GitHub token in your computer's credential store, and run the
   starter workflow.
3. Begin with listing stories. Write actions always show a preview and ask for
   confirmation.

The starter is configured for the personal `story-sandbox` repository only.
Do not use it with company data or a company repository unless your workplace
explicitly permits that access and token use.
